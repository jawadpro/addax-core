Blocks, projects, settings and page options for the Addax theme.

== Description ==

Hero slider, counters, progress and donut charts, info boxes, tabs, client logos, a filterable projects grid, team members, testimonials and a map block. Also adds the Projects post type, Addax Settings (contact details, social links, layout options) with block bindings, and per-page header/footer options.
